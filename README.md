# Oohra

Multiplayerová hra o přežití a civilizaci: jeden trvalý svět, skryté složení rostlin, generace, jazyk ze slabik, znalosti mizí smrtí.

- `docs/` dokumenty (návrh hry 0.7, plán vývoje, návod k instalaci)
- `prototype/` prototyp v prohlížeči (zdroj pravidel a čísel, otevři `oohra.html`)
- `server/` jádro hry v C# (Fáze A)
- `unity/` klient (Fáze B, zatím nic)

Pracovní pravidla jsou v `CLAUDE.md`.
